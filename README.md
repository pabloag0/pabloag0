## 🚀 Proyectos Destacados

### 🧠 [Credit risk — MLOps](#) 
*Proyecto personal*

Sistema MLOps end-to-end desplegado en producción para la predicción del riesgo crediticio.
- **Tecnologías:** GitHub Actions, Docker, Render, FastAPI, PostgreSQL.
- **Destacado:** CI/CD automático, trazabilidad de predicciones por versión del modelo, interfaz web y simulador de tráfico con feedback loop.

### 🍳 [SmartCook](#) 🏆
*Proyecto académico en equipo — Premio al Talento del Grado*

Aplicación web para la planificación semanal de recetas, lista de la compra automatizada e instrucciones.
- **Tecnologías:** Python, Flask, React, GitHub Actions.
- **Destacado:** Metodología ágil Scrum y CI/CD.

### 📊 [Clasificación de riesgo crediticio — Machine Learning](#)
*Nota: Sobresaliente*

Proyecto de clasificación binaria sobre un dataset de 45.000 solicitudes (Kaggle).
- **Tecnologías:** NumPy, PyTorch.
- **Destacado:** Comparación de regresión logística vs redes neuronales profundas, evaluación con validación cruzada y gestión de desbalanceo (undersampling y SMOTE).

### 📦 [PrimePC — Gestión comercial y logística](#)
*Proyecto universitario en equipo*

Aplicación de escritorio bajo arquitectura de 3 capas y patrones de diseño empresariales.
- **Tecnologías:** Java 17, JDBC, JPA, H2, JUnit 4, UML, Gantt.
- **Destacado:** Patrones de diseño (DAO, Command, Abstract Factory), arquitectura escalable y testing asegurado.

### 🎾 [Marcador inteligente de pádel](#)
*Proyecto personal*

Sistema IoT para conectar smartwatches y mostrar resultados deportivos en tiempo real.
- **Tecnologías:** ESP32, Bluetooth, C/C++.
- **Destacado:** Visión escalable orientada a clubes y análisis de rendimiento deportivo.
